## 项目简介

本项目构建一个面向个人锻炼者的微信小程序：用户将手机固定（或由他人拍摄），使用前置摄像头在端侧识别单人真实跳绳动作，在 30 秒 / 1 分钟 / 3 分钟三档预设时长内按起跳次数自动计数，结束后展示成绩并在本地保存记录，支持查看历史与按时长档位分别统计的个人最佳。

产品免登录、无云端同步、摄像头画面不上传；后续计划正式提交审核上线，面向所有个人锻炼者公开发布。

## 关键结论

- 产品形态：微信小程序，前置摄像头端侧识别，不上传画面。
- 核心流程：三档时长（默认 1 分钟）→ 姿势引导与镜像预览 → 起跳次数计数 → 最后 3 秒语音倒计时 → 自动停止 → 结果展示与本地保存 → 历史/分档个人最佳。
- 计数口径：仅真实跳绳；并跳、交替跳、交叉跳、双摇；按起跳次数计，双摇算 1 次；无绳空跳不计数。
- 语音反馈：每 10 次播报累计次数；最后 3 秒报 3、2、1；不播报剩余时间；无静音开关。
- 数据与账号：免登录、纯本地、无云端同步、无排行榜/社交。
- 一期验收：正常光照、单人、手机固定、1 分钟，100 次误差 ≤ ±5 次。
- 发布：个人主体小程序账号，面向所有个人锻炼者公开发布。
