### FR-001：时长选择

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-001 |
| 关联流程 | BPF-001 |
| 优先级 | P0-必须 |
| 涉及角色 | 个人锻炼者 |

**功能描述：**
用户进入小程序后，可在 30 秒、1 分钟、3 分钟三档预设时长中选择本次运动时长；未选择时默认使用 1 分钟。一期不提供自定义时长。

**用户故事：**
> 作为个人锻炼者，我希望在开始前选择 30 秒 / 1 分钟 / 3 分钟，以便按自己的安排完成计时跳绳。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| durationTier | enum(30, 60, 180) | 否 | 仅允许三档值 | 单位秒；默认 60 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 成功 | 选中的时长档位 | 传递至倒计时流程 |
| 未选择 | 1 分钟（60 秒） | 默认值 |
| 非法值 | 不适用 | 控件仅提供三档，不提供自由输入 |

**业务规则：**
1. 一期仅提供 30 秒、1 分钟、3 分钟三档（REQ-001）。
2. 默认选中 1 分钟（REQ-001）。
3. 不提供自定义时长（澄清轮次 5）。

**界面/交互要求（如适用）：**
- 首页提供三档选择控件，默认选中 1 分钟。
- 选择后用户可进入取景准备。

### FR-002：摄像头权限与前置取景

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-002 |
| 关联流程 | BPF-001 |
| 优先级 | P0-必须 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
小程序使用手机前置摄像头取景。首次进入取景页时申请摄像头权限；用户拒绝时展示开启引导，可重试或退出；摄像头不可用时提示并停止流程。

**用户故事：**
> 作为个人锻炼者，我希望小程序能正常使用前置摄像头，并在拒绝权限时得到清晰引导，以便顺利开始计数。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| cameraPermission | boolean（系统状态） | 是 | 由微信客户端返回 | 摄像头授权状态 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 已授权 | 前置摄像头就绪，进入预览 | 无额外提示 |
| 未授权 | 系统权限申请 | 首次进入或权限未授权时申请；拒绝后重试可再次触发 |
| 拒绝授权 | 开启引导页 | 可重试或退出，不崩溃 |
| 摄像头不可用 | 异常提示并结束流程 | 派生处理 |

**业务规则：**
1. 使用前置摄像头（REQ-002、澄清轮次 3）。
2. 首次进入取景页申请权限；拒绝后展示开启引导（REQ-002，权限处理为派生）。
3. 权限拒绝或摄像头不可用时不得崩溃（SC-002-2）。

**界面/交互要求（如适用）：**
- 权限开启引导需说明用途与开启方式（派生）。
- 摄像头不可用时展示提示并提供退出路径（派生）。

### FR-003：实时镜像预览

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-003 |
| 关联流程 | BPF-001、BPF-002 |
| 优先级 | P1-重要 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
在前置摄像头就绪后，实时显示摄像头画面，并按镜像方式呈现，便于用户调整站位与观察自身动作。

**用户故事：**
> 作为个人锻炼者，我希望看到镜像的实时画面，以便像照镜子一样调整位置和动作。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| cameraStream | 视频帧流 | 是 | 前置摄像头输出 | 仅端侧使用 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 正常 | 镜像实时预览 | 方向与真实动作一致 |
| 帧率不足 | 降低预览质量或提示 | 派生处理，待方案阶段确认 |

**业务规则：**
1. 使用前置摄像头（REQ-003）。
2. 画面按镜像方式呈现（REQ-003、澄清轮次 4）。
3. 实时预览帧率 ≥ 15fps、延迟 ≤ 200ms（SC-003-1；指标定义见 NFR-PERF-002，延迟为派生观测项）。

**界面/交互要求（如适用）：**
- 预览区域展示前置摄像头镜像画面。
- 预览与计数过程叠加计数、倒计时等必要信息（派生）。

### FR-006：跳绳识别与计数

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-006、REQ-007、REQ-008 |
| 关联流程 | BPF-002 |
| 优先级 | P0-必须 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
在端侧识别画面中单人的真实跳绳动作，按起跳次数累计计数；支持并跳、交替跳、交叉跳、双摇；双摇按一次起跳计 1 次；无绳空跳不计数。

**用户故事：**
> 作为个人锻炼者，我希望系统自动识别我的真实跳绳并按起跳次数计数，以便无需手动数数。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| cameraFrames | 视频帧 | 是 | 前置摄像头画面 | 仅端侧处理 |
| personCount | number | 是 | 仅支持 1 人 | 多人同框不在本期支持范围 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 真实跳绳起跳 | 计数 +1 | 四种跳法均按起跳计 |
| 双摇一次起跳 | 计数 +1 | 不按绳子过脚次数计 |
| 无绳空跳 | 不计数 | 仅甩腕动作同样不计数 |
| 画面无人 | 不计数 | 倒计时继续 |

**业务规则：**
1. 仅统计真实跳绳；无绳空跳不计数（REQ-006）。
2. 计数单位为起跳次数，双摇按一次起跳计 1 次（REQ-007）。
3. 支持并跳、交替跳、交叉跳、双摇（REQ-008）。
4. 画面中仅支持一人；多人同框不在本期支持范围（REQ-006、澄清排除项）。
5. 准确率目标见 NFR-PERF-006：正常光照、单人、手机固定、1 分钟，与人工计数对照，100 次误差 ≤ ±5 次（REQ-012）。

**界面/交互要求（如适用）：**
- 实时展示当前计数（派生）。
- 计数只增不减，归零后停止。

### FR-007：倒计时与自动停止

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-009、REQ-010 |
| 关联流程 | BPF-002 |
| 优先级 | P0-必须 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
按用户所选档位进行 30 秒 / 1 分钟 / 3 分钟倒计时；倒计时归零后自动停止计数并进入结果流程，停止后继续跳绳不再增加本次计数。

**用户故事：**
> 作为个人锻炼者，我希望时间到自动停止并给出结果，以便得到固定时长的成绩。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| durationTier | enum(30, 60, 180) | 是 | 来自 FR-001 | 单位秒 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 倒计时中 | 剩余时间 | 每秒更新（派生） |
| 归零 | 停止计数，进入结果 | 停止时延 ≤ 1 秒（SC-010-1） |
| 归零后继续跳 | 本次计数不变 | 不再累加 |

**业务规则：**
1. 按 30 秒 / 1 分钟 / 3 分钟倒计时（REQ-009）。
2. 归零后自动停止并进入结果（REQ-010、澄清轮次 5）。
3. 停止后继续跳绳不增加本次计数（SC-010-2）。

**界面/交互要求（如适用）：**
- 计数过程中展示剩余时间（派生）。
- 最后 3 秒由 FR-008 负责语音提示。

### FR-008：语音反馈

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-014、REQ-015 |
| 关联流程 | BPF-002 |
| 优先级 | P1-重要 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
每累计 10 次起跳，语音播报当前累计次数（如「30 次」）；倒计时最后 3 秒按整秒边界分别播报「3」「2」「1」，同一秒值仅播报一次；不播报剩余时间；不提供静音开关。

**用户故事：**
> 作为个人锻炼者，我希望在运动中听到累计次数和最后 3 秒倒计时，以便掌握节奏而无需看屏幕。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| currentCount | number | 是 | 非负整数 | 当前累计次数 |
| remainingSeconds | number | 是 | 0–180 | 剩余秒数 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 累计次数为 10 的倍数 | 播报当前累计次数 | 如「30 次」 |
| 到达剩余 3/2/1 秒边界 | 分别播报「3」「2」「1」 | 每个秒值仅一次 |
| 其他时刻 | 无播报 | 不播报剩余时间 |
| 语音播放失败 | 计数继续 | 不影响结果 |

**业务规则：**
1. 每 10 次语音播报累计次数（REQ-014）。
2. 最后 3 秒按整秒边界播报 3、2、1，每个秒值仅一次（REQ-015、SC-015-1）。
3. 不播报剩余时间（澄清轮次 7）。
4. 不提供静音开关，语音始终开启（REQ-014、澄清轮次 3）。
5. 语音播放失败不影响计数与结果（派生）。

**界面/交互要求（如适用）：**
- 不提供静音开关。
- 语音内容使用中文数字，如「30 次」。

### FR-010：本地记录保存

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-017 |
| 关联流程 | BPF-003 |
| 优先级 | P1-重要 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
每次计数完成后，在本地保存一条记录，包含日期、次数、时长；关闭并重新打开小程序后记录仍存在；写入失败时提示保存失败，结果仍可查看，且不更新个人最佳。

**用户故事：**
> 作为个人锻炼者，我希望每次成绩自动保存在本机，以便以后查看历史。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| record | object | 是 | 含 date、count、duration | 本次记录 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 成功 | 本地记录 +1 | 持久化 |
| 写入失败 | 保存失败提示 | 结果仍可查看，不更新最佳 |

**业务规则：**
1. 每次完成保存一条本地记录，包含日期、次数、时长（REQ-017）。

| 关联流程 | BPF-003、BPF-004 |
| 优先级 | P1-重要 |
| 涉及角色 | 个人锻炼者、端侧识别系统 |

**功能描述：**
按时长档位分别统计并展示个人最佳：30 秒、1 分钟、3 分钟各自保留该档位历史最高次数；新纪录超过该档最佳时更新，否则保持不变；不同档位互不影响。

**用户故事：**
> 作为个人锻炼者，我希望看到每个时长档位的个人最佳，以便比较自己的进步。

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|---------|------|
| records | array | 是 | 含 duration、count | 本地记录集合 |
| durationTier | enum(30, 60, 180) | 是 | 三档 | 统计维度 |

**输出/响应：**

| 场景 | 输出内容 | 说明 |
|------|---------|------|
| 有记录 | 三档最佳值 | 各档最高次数 |
| 新纪录 | 更新对应档位 | 不超过则不变 |
| 无记录 | 占位值 | 派生 |

**业务规则：**
1. 个人最佳按时长档位分别统计（REQ-019、澄清轮次 8）。
2. 仅比较同档位记录，跨档位互不影响（SC-019-3）。
3. 无记录时显示占位值（派生）。

**界面/交互要求（如适用）：**
- 历史页或独立区域展示三档最佳。
- 最佳值需标注对应档位，避免跨档误读。

### FR-013：免登录使用

| 属性 | 内容 |
|------|------|
| 来源需求 | REQ-020 |
| 关联流程 | BPF-001 |

**输入：**

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
