# 非功能需求

## 元信息

| 属性 | 值 |
|------|-----|
| 项目编码 | PRJ-001 |
| 项目名称 | 微信跳绳计数器 |
| 文档版本 | v1.1 |
| 创建日期 | 2026-10-30 |
| 最后更新 | 2026-10-30 |

> 说明：以下目标值为当前规格基线，与 P3 成功标准一致；标注「待校准」的指标需在开发启动前通过目标机型实测后锁定。NFR-PERF-001（识别帧率）与 NFR-PERF-002（预览帧率与延迟）是两个独立指标，二者均以 15fps 为基线但测量对象不同。

---

## 性能需求

| 编号 | 需求描述 | 指标 | 目标值 | 测量方法 | 优先级 |
|------|---------|------|--------|---------|--------|
| NFR-PERF-001 | 端侧识别需支撑实时计数（REQ-013 / SC-013-1） | 识别帧率 | ≥ 15fps；热压力期间绝对下限 ≥ 10fps（待校准） | 目标机型性能工具统计，取预热后识别阶段的帧率均值 | P1-重要 |
| NFR-PERF-002 | 前置摄像头预览需实时流畅（REQ-003 / SC-003-1） | 预览帧率、预览延迟 | 帧率 ≥ 15fps；延迟 ≤ 200ms（延迟为派生观测项，待校准） | 帧率用性能工具统计；延迟用秒表与预览画面同框拍摄比对 | P1-重要 |
| NFR-PERF-003 | 倒计时归零后及时停止计数（REQ-010 / SC-010-1） | 停止时延 | ≤ 1 秒 | 功能测试计时 | P0-必须 |
| NFR-PERF-004 | 停止计数后及时渲染结果页（REQ-016 / SC-016-2） | 结果页首帧时延 | ≤ 2 秒（派生） | 功能测试计时 | P0-必须 |
| NFR-PERF-005 | 最后 3 秒语音播报与实际秒同步（REQ-015 / SC-015-1） | 播报时间误差 | ≤ 0.5 秒 | 录屏音轨与计时器时间戳比对，或程序日志时间戳核对 | P1-重要 |
| NFR-PERF-006 | 计数准确率（REQ-012 / SC-012-1、SC-012-2） | 与人工计数的误差 | 正常光照、单人、手机固定、1 分钟条件下，以 100 次为基准误差 ≤ ±5 次；连续 5 次均满足（不足 100 次按比例换算） | 人工对照测试 | P0-必须 |
| NFR-PERF-007 | 授权后前置摄像头及时出画（REQ-002 / SC-002-3） | 授权到预览首帧时延 | ≤ 2 秒 | 功能测试计时 | P0-必须 |
| NFR-PERF-008 | 档位传入与倒计时总时长准确（REQ-001、REQ-009 / SC-001-2、SC-009-1） | 实际倒计时与设定值之差 | ≤ 1 秒（30 / 60 / 180 秒三档） | 秒表测试 | P0-必须 |

## 可用性与可靠性

| 编号 | 需求描述 | 指标 | 目标值 | 测量方法 | 优先级 |
|------|---------|------|--------|---------|--------|
| NFR-REL-001 | 连续使用稳定性（REQ-013 / SC-013-2） | 闪退与计数中断次数 | 连续使用 5 分钟，0 次闪退、0 次计数中断（派生） | 目标机型实测 | P1-重要 |
| NFR-REL-002 | 本地记录持久化（REQ-017 / SC-017-2） | 重启后记录可见性 | 关闭并重新打开小程序后记录仍存在 | 功能测试 | P1-重要 |
| NFR-REL-003 | 权限拒绝或摄像头不可用时不崩溃（REQ-002 / SC-002-2） | 崩溃次数 | 0 次，且展示引导或提示 | 功能测试 | P0-必须 |
| NFR-REL-004 | 本地写入失败时不产生「有最佳、无历史」不一致（REQ-017、REQ-019，派生） | 数据一致性 | 写入失败时个人最佳不更新 | 故障注入测试 | P1-重要 |
| NFR-REL-005 | 连续使用温升与耗电不导致不可用（REQ-013 / SC-013-3） | 帧率下降、中断、外壳温度、电量差 | 连续完成 30 秒 / 1 分钟 / 3 分钟各一次后：识别帧率相对初始值下降 ≤ 30%，且正常阶段 ≥ 15fps、热压力期间 ≥ 10fps；0 次计数中断；外壳温度 ≤ 45℃（环境 25±2℃）；电量消耗 ≤ 15%（起始电量 ≥ 50%）。占位阈值，待校准 | 初始帧率取预热后首 30 秒均值；性能工具统计帧率、测温设备测外壳温度、系统电量统计测耗电 | P1-重要 |
| NFR-REL-006 | 识别与计数不依赖网络（REQ-011，派生） | 断网可用性 | 无网络时识别、计数、结果展示与本地保存仍可用；语音优先使用本地音频（与 NFR-MAI-003 相关） | 断网测试 | P1-重要 |

## 安全需求

| 编号 | 需求描述 | 安全类别 | 具体要求 | 测量方法 | 优先级 |
|------|---------|---------|---------|---------|--------|
| NFR-SEC-001 | 摄像头画面不上传（REQ-011 / SC-011-1） | 数据安全 | 运动全程无图片、视频或摄像头帧上传请求 | 抓包 + 网络监控 | P0-必须 |
| NFR-SEC-002 | 成绩与历史不上传（REQ-021 / SC-021-1、SC-021-2） | 数据安全 | 无成绩/历史数据上传请求；清除本地数据后记录消失且不可从云端恢复 | 抓包 + 数据清除测试 + 接口清单审查 | P0-必须 |
| NFR-SEC-003 | 不请求用户身份信息（REQ-020 / SC-020-2） | 身份与隐私 | 不调用获取用户信息、手机号等接口；无登录/注册流程 | 接口清单审查 + 代码审查 | P0-必须 |
| NFR-SEC-004 | 隐私协议与实际实现一致（REQ-023 / SC-023-2） | 合规 | 声明摄像头用途、端侧处理、本地存储，且与实现一致 | 隐私协议与实现逐项对照审查 | P0-必须 |
| NFR-SEC-005 | 最小权限原则（REQ-002、REQ-020，派生） | 权限管理 | 仅申请摄像头权限；不申请与功能无关的权限 | 小程序权限清单审查 | P1-重要 |
| NFR-SEC-006 | 日志与崩溃信息不含画面或个人信息（派生） | 数据安全 | 日志仅记录必要技术信息，不包含摄像头画面、用户身份信息 | 日志抽样审查 | P1-重要 |
